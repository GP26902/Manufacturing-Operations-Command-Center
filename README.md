# Manufacturing Operations Command Center 🏭

An industrial-grade, multi-module Streamlit web application designed for manufacturing quality control, equipment reliability, and Six Sigma project tracking.

## Features Included
1. **SPC Quality Control Module**: Real-time X-bar and R control charts with dynamic subgroup calculations and control limit tracking.
2. **OEE Dashboard**: Tracks Availability, Performance, and Quality to compute total Overall Equipment Effectiveness.
3. **Pareto Defect Analysis**: Applies the 80/20 rule to prioritize primary manufacturing defect categories.
4. **Maintenance & Downtime Tracker**: Computes Mean Time Between Failures (MTBF) and Mean Time To Repair (MTTR) metrics.
5. **Six Sigma DMAIC Kanban Board**: Interactive card-based workflow management across all five DMAIC phases utilizing session state.
